# ABI Tests

This domain protects boundaries where Cyna must match external C or binary
expectations.

Planned subareas:

- `c_interop/`
- `layout/`
- `symbols/`
- `headers/`
- `boundary_ownership/`
- `cross_target/`
- `inline_assembly/`

Current suite imports carried-forward C ABI, layout, lower/backend shape, and
target checks.
